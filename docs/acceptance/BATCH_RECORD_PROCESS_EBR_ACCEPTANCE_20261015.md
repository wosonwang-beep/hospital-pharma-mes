## 记录映射

氯化钾溶液包括称量投料、溶解配制、过滤、分装、贴签包装和清场。EBR 覆盖原辅料批号与实投量、首次加水量、搅拌时间、半成品性状与含量、药瓶/标签领用使用损耗退回、成品数量、总体积、物料平衡、成品率和清场记录。

喉咽茶合剂包括水提投料、两次提取、浓缩、配制、分装与装量检查、贴签包装和清场。EBR 覆盖四味药材批号与实投量、每锅加水、蒸汽压力、提取温度、提取液体积、真空度、浓缩体积、蔗糖与苯甲酸钠投料、搅拌/加热时间、装量抽查、药瓶/标签物料平衡、产量、留样、入库和清场记录。

原批次检验报告中的历史实测结果保留在原始资料中，不预填进生产模板；成品质量检验继续作为批记录目录中的质量业务记录引用。
