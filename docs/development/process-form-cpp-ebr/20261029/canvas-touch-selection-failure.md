# Canvas 触屏选区复现记录

环境：mes-demo，5173，本地Chrome 375×900，Playwright触屏模拟；禁止非GET/HEAD和非本机请求。不是实体手机验证。

`canvas-touch-check-20261029.mjs` 先验证触屏正反向滑动：scrollLeft 0 → 453 → 0。点击画布后点击“插入文本输入”，初始版本字段数量3→4，但画布文档没有该字段编码；失败签名“字段定义已增加，但画布未包含对应字段”。诊断观察当前选区为startIndex=-1、endIndex=-1；DOM画布可能存在多次挂载，直接读取Vue暴露的editor引用可能是旧实例，不能仅凭该诊断认定全部选区实现根因。

无选区单独复现 `canvas-insert-no-selection-check-20261029.mjs`：首次失败“无画布选区时产生孤立字段”。第18轮仅增加缺选区保护及可操作提示，修复后该脚本通过（字段3→3），鼠标定位后的内存测试仍能增加字段并验证画布文档包含该字段编码。

修复后原触屏流程仍不能成功插入，签名由“字段定义已增加，但画布未包含对应字段”变为“触屏插入字段后定义未增加”。同一触屏插入目标未达成，保留原断言与失败结果，按重复失败停止继续针对该触屏问题自动修复；未经进一步有效证据不能断言是框架不支持触屏或是某一坐标问题。画布横向滚动、无选区保护和鼠标有效选区是分项结果，不构成触屏编辑通过。没有真实业务写入。
