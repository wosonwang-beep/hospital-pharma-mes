# 内部物料批号 YYYYMM + 四位流水

用户本对话原文：“内部批号为年月+四位流水号”。关联此前已明确A（系统分配内部物料批号）及原型进入开发授权。状态：用户已确定编号格式，本机开发环境实施授权；不是捏造医院SOP编号或质量放行签名。

编号采用 `YYYYMMNNNN`，十位纯数字，无RM前缀、无分隔符。示例2026100001、2026100002，次月2026110001。工程解释为每个组织、每个自然月共用流水，不按物料各自重置；沿用本项目Asia/Shanghai业务日期。每月0001–9999，耗尽即阻断，不能回绕或扩成第五位。取消/放弃的预约号仍留存、不回收；已保存/已确认的历史号保持原样。跨月重试同一行仍返原号；规则重配不把已用号重新分配。
