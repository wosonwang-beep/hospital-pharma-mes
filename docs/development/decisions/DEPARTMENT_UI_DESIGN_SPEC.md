## 页面与视觉
- Global UI V2、统一七域导航；路径：系统管理 / 部门管理。实际业务界面不展示“设计图/T1/版本”字样。
- T1：顶部页面标题+新增部门；查询卡片；左部门树；右结果列表与分页。
- 查询标签与控件始终同行；部门编码宽 132px，部门名称 148px，状态 106px，间距 12–16px；查询/重置紧跟最后一项。窄屏整组换行，不允许标签独占一行。
- 列表字段：部门编码、部门名称、上级部门、所属组织、负责人、状态、显示排序、操作；不显示内部数据库 ID/版本/审计。
- 简单新增/编辑使用居中弹窗（依据 DCP-DATABASE-MENU-AND-USABILITY-001）；查看使用 T3 只读详情；所有表单标签控件水平配对。

## 原型可操作交互
1. 查询：输入编码、名称、状态，点击查询才生效；重置清空条件/部门树并返回第一页；无结果显示空态。
2. 部门树：点击部门，展示该部门及下级；“全部部门”取消限定；分页随筛选重置。
3. 列表：分页、查看、编辑；只读权限模式隐藏新增/编辑；可模拟接口错误与重试。
4. 新增：打开弹窗、字段校验（编码/名称必填、编码唯一）、保存后模拟更新列表、取消不保存。
5. 编辑：回显字段、部门编码只读、父部门排除自己和后代、保存模拟更新。
6. 查看：只读详情并可返回列表；不得将只读详情伪装成编辑表单。
7. 状态：ACTIVE/INACTIVE 展示启用/停用；原型模拟选项，正式绑定 DEPARTMENT_STATUS。
8. 错误：输入验证错误在对应字段下方；模拟查询错误显示重试入口。
