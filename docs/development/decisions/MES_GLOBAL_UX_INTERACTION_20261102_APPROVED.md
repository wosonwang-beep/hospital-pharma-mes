# MES 全局业务页面与子列表交互统一规范（2026-11-02）

状态：**USER APPROVED / ACTIVE — 规范与设计原则已批准；单页具体原型版本尚未批准**。
批准来源：用户在当前对话依次确认了基础管理物料整改、子列表新增/编辑弹窗、主次按钮顺序、查询/重置顺序、T2 标题栏简化，并再次确认原型必须同样遵守。

## 适用与边界
- 面向 MES 所有普通 T1 查询/列表与 T2 新增/编辑业务页面，以及其子列表编辑弹窗；新原型和现有页面改版都必须遵守。特殊 T4/T5/T6 和专业设计器保留已有批准业务布局，任何调整先核对既有 DESIGN LOCK。
- 普通 T2 页面标题栏仅显示“新增/编辑 + 业务对象名称”；不显示副标题、说明文字、返回列表链接、重复业务名称/编码/状态摘要；对象信息可置于正文，操作区保留取消/返回逻辑与未保存保护。T3 只读详情标题栏按已批准 T3 规则，不受此标题简化直接替换。
- T2 中子列表/子表“新增”和“编辑”一律通过居中对话框完成；禁止行内编辑及在列表下方展开编辑表单。新增入口放子列表标题栏右侧；操作列主编辑在辅助查看之前；撤销/停用等受控动作遵循自身权限与业务规则，危险按钮排在操作组末端。此条是普通业务子列表的 UI 约束，不授权改变已有复杂专业编辑器或跨页面业务流程。
- 所有同一操作组从左到右：主功能 → 辅助功能 → 危险操作。T1 查询/重置为 `查询 → 重置`，并保持紧邻筛选条件、右对齐；重置恢复默认筛选、排序、第一页并重新查询。T2 底部为 `保存/提交 → 取消/返回`，弹窗底部为 `保存/确认 → 取消`，整体右对齐，窄屏整组换行但顺序不变；Ant Design Vue 默认弹窗 footer 须自定义修正。
- 查询和编辑表单标签与控件必须同一水平行，宽度不足整体换行。弹窗打开、取消、保存和失败/409 不得丢失主页面未保存的输入。离开页面时应保护草稿并提示；错误信息清晰、保留当前输入并支持安全重试，不以粗暴重新加载覆盖用户工作。
- 任何实现必须保持已有字段、状态、权限、GMP、审计、接口与事务边界；用户在此前批准的基础资料自动维护原因规则继续有效，不新增人工原因强制输入。
