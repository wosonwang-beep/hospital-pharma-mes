## 已实施行为

模板版本保存 `printType=DOCUMENT/LIST`。businessType 是业务页面的数据源绑定键；printType 决定输出结构。调用页面仅发送数据源、选中 ID、模板 ID 和既有 formal 标记，不发送输出模式或事实正文。同一组 ID 选择单据模板时逐单据填充明细并分别分页，选择列表模板时将各记录抬头事实填充为循环列表。旧模板默认 DOCUMENT；改变类型追加新版本。

Canvas 编辑页 T2、模板列表 T1 保留用户设计的元数据、来源选择、分组字段、字段插入、循环表、绑定属性、Word 导入、预览及发布。来源和字段目录从实际注册 provider 读取。新增循环表的字号在控件序列化与 Word 导出间保持一致；首次插入位于标题和标识之后。WMS 收货查询 T1、检验报告查询 T1 支持勾选打印；收货详情 T3 复用单条入口。分页保留勾选，查询条件变更清除旧选择。没有适用模板时显示原因并禁止生成。

新接入 WMS_RECEIPT 实际收货数据、供应商/仓库/人员引用、物料快照、包装规格、批号、实际数量和单位。优先已有确认快照。不虚构联系人、电话、备注或混合单位合计。当前实际注册来源为收货单、检验报告、eBR 过程表单；其他业务来源未自动接入。eBR 既有单据消费方式保留，不宣称整册批量流程已重新验收。

批量输出追加不可变归档：模板、选中顺序、源事实或逐单据归档引用、源版本、快照摘要、PDF 及摘要。再次读取使用原 PDF，不重新取数生成。每个源 ID 重新核验组织及读权限。列表不能冒充正式签署报告；正式检验单据继续使用原批准、签名及幂等规则。业务锁按 ID 升序获取，输出仍按勾选顺序，避免与单条打印的锁顺序冲突。合并输入与最终 PDF 限制25MB，避免累积100份最大输出；超限整体回滚。
