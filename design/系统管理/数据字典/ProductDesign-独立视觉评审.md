## 原型技术/交互自检

- Chromium 渲染了 6 个主场景，加字典项编辑、导入预检 2 个交互场景。
- 全部无页面 JavaScript Error，全部页面无横向 overflow。
- 原型事件检查：字典 CODE 搜索/重置 → 点击项目数量 → 打开弹窗 → 添加原型字典项 → 关闭弹窗，全链成功。
- **仅检查原型自身**。示例数据保存在原型脚本里，改动只影响浏览器内存，未连接真实字典数据库，不代表数据库持久性或后端接口测试通过。

## 真正实施前的未完成约束

1. `sys_dict_type/sys_dict_item` 当前共享 MariaDB 库中尚未建立，必须审查 schema、权限、审计及现有 Flyway history 后创建新的 append-only 迁移。
2. 业务类型/设备类型/物料类型等可配置下拉必须从字典接口读取，不能把本原型示例项复制成 Vue 硬编码；有静态候选需迁移与验证。
3. 树形字典必须有真实的 parent/child 主键关系，避免仅靠展示缩进模拟持久层级。
4. 导入导出需 CSV/Excel 文件解析、重复 CODE 冲突判定、幂等、批量事务及失败记录，不能因示例弹窗成功就声称已实现。
5. 必须进一步对照当前 5173 登录后的真实页面截图，完成业务 CRUD、菜单权限、审计、字段绑定和字典停用历史回显；只有截图对照+交互+数据库验证通过才可标记功能已验收。
6. 部门、用户、菜单、角色、角色权限仍在系统管理独立排期，不能因为字典设计完成就标记其他模块为已完成。

**产品设计完成 ≠ 工程实现完成 ≠ 最终业务验收完成。**
