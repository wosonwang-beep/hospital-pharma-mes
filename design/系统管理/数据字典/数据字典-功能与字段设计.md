# 系统管理 · 数据字典功能设计方案（设计阶段）

状态：**待视觉评审 / 未实现 / 非数据库已存在功能**。

## 1. 明确约定

类型类可配置下拉选项，先定义数据字典类型和字典项，将配置持久保存到本地 MariaDB 开发库，再由业务页面调用字典 API 展示。Vue 页面和 TypeScript 资源目录不再维护第二份同类静态选项，也不在 API 异常时悄悄回退为前端写死的列表。

**三种数据来源必须区分**：
- **数据字典**：类型、类别、通用且允许系统管理员维护的业务选项（例如经业务确认可以修改的设备类型、物料类型）。字典项用于业务表单选择。
- **主数据实体**：部门、人员、角色、仓库、单位、供应商、产品、设备等，是有标识、生命周期与关系的实体；通过专用主数据接口检索，不能用普通字典项替代。
- **受控业务状态/规则**：生产批生命周期、IQC 检验判定、QA 放行状态、eBR 审批等受状态机、权限和 GxP 约束；**禁止管理员通过数据字典修改状态码或流程语义**。允许单独做只读中文标签映射，但不可改变服务端规则。

## 2. 建议的数据库结构（经实施前审查后以新增 Flyway 迁移落地）

1. `sys_dict_type` 字典类型：`id,org_id,dict_code,dict_name,description,status,sort_no,version_no,created_by,created_at,updated_by,updated_at`。
2. `sys_dict_item` 字典选项：`id,org_id,dict_type_id,item_code,item_label,sort_no,status,is_default,description,version_no,created_by,created_at,updated_by,updated_at`。
3. 唯一性：`(org_id,dict_code)`、`(org_id,dict_type_id,item_code)`；有效默认项同类型最多一条，由服务校验或唯一条件约束实现。
4. 类型编码与已引用选项值稳定；已被业务记录引用时禁止物理删除或随意更改选项编码，历史值仍应能展示原名称/快照。
5. 配置审计必须记录操作者、操作时间、变更前后、引用状态、版本和结果，角色权限控制创建、编辑、停用、查看；不将字典管理权限默认授予普通业务岗位。
6. 程序不允许自行执行 SQL 修改历史受控记录，不允许更改已应用 Flyway；正式实施前审查依赖关系和现有最高 migration。

## 3. 下拉的数据接口与动态行为（规划，不代表现有 API）

- 业务页面按 `dictCode` 查询字典项；返回选项编码、名称、排序、可用状态，由服务端统一按组织、启用状态筛选。
- 关键交互：远程搜索、按 sort 排序、支持清空（非必填）、停用项不可新选，但老记录回显必须正确。
- 新建/编辑字典类型与字典项的结果更新相应选项缓存；页面无需重新部署即可使用更新后的配置。
- 字典类型被停用时不能用于新增选择，但历史业务记录与明细保留显示。
- 不允许前端配置一个服务端不认识的任意数据值绕过字段校验；前端必须显示加载失败，禁止伪装选项已加载。

## 4. 系统管理数据字典页面规划（PC 1440×900）

### A. 数据字典-查询（T1）
顶部标题/简明操作，查询区：字典名称、字典编码、状态；表格列：字典名称、编码、字典项数量、状态、排序、操作（查看、编辑、配置字典项）。不显示无意义的内部数据库 ID、版本号、审计 JSON。

### B. 数据字典-新增（T2）
字典名称、字典编码、说明、状态、排序；保存/取消。新增页面与列表分离。

### C. 数据字典-编辑（T2）
显示不可随意修改的编码；编辑名称、说明、状态与排序，下方可维护字典项（编码、标签、顺序、默认、启停）；区分「保存字典类型」和「保存字典项」，避免无意覆盖。

### D. 数据字典-查看（T3）
类型摘要、状态，字典项查询与列表；已停用项展示为不可新选；允许被引用的历史项继续回显。

## 5. 现状差距（截至本次审查）

- 在当前共享数据库的元数据中，未查询到专用的 `sys_dict_type/sys_dict_item` 字典表；必须先设计、审查、再迁移。
- 前端 `frontend/mes-web/src/master/resources.ts` 存在 `choices` 静态数组，`MasterDetailView.vue` 直接遍历 `f.choices` 生成选项。属于后续逐项迁移候选。
- `SysUserEntity` 无明确部门关联字段，目前 `md_organization` 只有组织层级和组织类型，不能混淆成部门主数据。
