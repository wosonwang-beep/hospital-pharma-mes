## 3. 控件字段与源契约

| 设计控件 | 字段/来源 | 交互约束 |
|---|---|---|
| 角色编码 | Role.roleCode | 创建后只读，不能在编辑时改 |
| 角色名称 | Role.roleName | 可编辑、必填 |
| 状态 | Role.status：ACTIVE / INACTIVE | 现有领域受控值，不擅自写成自由维护字典 |
| 已选菜单与目录树 | Role.menuCodes + /menus | 按后端菜单树和组织/权限过滤授权 |
| 普通权限 | Role.permissionCodes + /permissions | 只有“只查看 / 增删改查”两个批准级别 |
| 特殊操作权限 | /permissions 现有真实功能编码 | 逐条授权，无条目时展示空态；禁止伪造操作 |
| 变更预览 | 前后 permissionCodes 的差集 | 显示新增和移除，不作为审批操作 |
| 保存角色信息 | 现有 PUT /roles/{id} | 保留 idempotency + If-Match + 权限校验 |
| 保存菜单与权限 | POST /roles/{id}/permissions | menuCodes 与 permissionCodes 一并提交 |

图中“质量审核员 / ROLE_QC”、选中菜单、功能数量等均为**视觉示例数据**，不得作为数据库、现有用户或系统权限事实。原型阶段会明确标注模拟来源，正式开发只使用实际后端返回值。
