# 医院制剂 MES 全系统 PC 页面设计与视觉验收规则

## 适用范围
整个 MES 所有功能菜单以及登录、首页、业务上下文页面，**仅 PC 端**。不生成手机设计图、不做移动端适配、不执行移动端视觉验收。
设计基准屏幕 1440×900，补充检验 1280×800 和 1536×1024 桌面分辨率，遵循既有 Global UI Design System V2 与页面模板 T1–T6。

## 输出结构
设计图统一放在仓库根目录 `design` 文件夹中，使用 **一级菜单/功能菜单/中文功能菜单名-页面类型.png** 命名，例如：
- `design/系统入口/登录/登录.png`
- `design/系统管理/角色与权限/角色与权限-查询.png`
- `design/系统管理/角色与权限/角色与权限-编辑.png`
- `design/基础管理/物料主数据/物料主数据-查询.png`
- `design/基础管理/物料主数据/物料主数据-新增.png`

同一功能有查询、新增、编辑、查看、审核、执行、设计器等不同结构时必须分别出图。
实施截图放在相应功能目录的 `review` 下，保存原型图、实现截图、差异对照与评审结论。不得把待完成文件当作真实设计图或声称已经完成。

## 强制施工顺序（逐页）
1. 从本机现有 `main` 工作区的真实 **MariaDB 菜单**、前端路由、页面字段/API 及 UI 基线收集该功能页面要求；不凭空编造字段。**先查找用户此前确认过的冻结原型**（例如 `releases/*/ui-prototype/screens/UI-EBR-DESIGNER.png`），有原稿就以原稿作为主要视觉来源，禁止重新发明设计或以当前实现反向定义目标。
2. **先画/恢复 PC 设计图，不改业务代码**。图中展示实际字段组、控件、操作区、表格列、状态与完整页面结构。若原稿存在，原样归档并核实实际可用的源原型 HTML/CSS/JS；任何因后续业务变更产生的差异必须明确标注，不能擅自改版。
3. **由 ChatGPT 自主做视觉与交互评审**，评审不依赖编译、HTTP 200 或接口测试：重点检查布局、美观、视觉层级、字体、配色、留白、宽度、行高、控件对齐、可读性、操作效率、一致性；不合格要先重画设计图。
4. 只有设计图经过视觉自评并满足业务字段契约，才能按图修改当前 `main` 工作区的真实源文件。Codex 不能自由设计新的结构、颜色、控件和导航。
5. 对 **同分辨率** 的设计图与运行在本地 5173 的实际页面逐屏截图对照，复查位置、尺寸、字体、留白、表格、搜索、弹层和按钮交互，记录每一项偏差，持续修改直到验收要求满足。
6. 页面视觉验收必须由真实截图支持；单元测试、接口测试、Playwright API Mock 通过不等于页面设计通过。自动化接口验证只是另一道功能质量门。
7. 页面完成标记必须同时具备：设计图、自主视觉评审通过、真实实施截图、差异对照通过、真实业务操作通过。否则一律标记 **待设计/待整改/待验收**。

## 已批准的 UI 字段同行规则（不可放宽）

依据 `MES_GLOBAL_UI_DESIGN_SYSTEM_V2.md` 第 6/9 节、`MES_PAGE_TEMPLATE_STANDARD_V2.md` 的 T1/T2，及最终冻结补充 `DCP-UI-LIST-EDIT-001`、`DCP-MATERIAL-NAMES-UI-001`：

- **查询区（T1）、新增/编辑（T2）、详情中的字段输入、字典项编辑弹窗**，标签在左、输入框/下拉/日期/多行文本控件在右，**同一水平行**。不得上标签、下控件；不得以视口变窄为理由自行上下换行。
- PC 查询区按批准样式安排 **3 列字段组**，每组约 130px 的右对齐标签及右侧控件；可以有多排字段组，但**同一字段组绝不拆行**。
- PC 新增/编辑 **2 列字段组**，标签统一约 130px 右对齐、必填星号与标签同行；长文本区域可跨两列，但标签仍放左侧同一行。
- 对屏幕不足的情况，只能减少同排字段组数量/使用受控横向滚动，不得偷偷改成上下标签。
- 颜色和尺寸遵循已批准的 `DCP-UI-LIST-EDIT-001`：背景 `#f0f2f5`、主按钮 `#2c5cdc`、卡片 4px 圆角、查询三列/编辑两列、13px 紧凑表格与 18px 页标题；不能随意再创一套风格。
- **验收硬门槛**：截图主观审查之外，还要对查询、新增、编辑和弹窗各控件做浏览器矩形定位，验证标签在控件左侧并存在水平垂直交叠；有任何一个标签位于控件上方，即本页面设计 FAIL，先修设计稿再施工。

**用户已明确：仅需 PC 页面，不做移动端原型或验收。** 原来的批准补充虽含移动端条款，但当前交付仅按 PC 验收。
